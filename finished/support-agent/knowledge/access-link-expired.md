# My access link expired or does not work

Last checked: 2026-10-01 · Owner: Support lead · Link: https://kitebridge.example/help/access-link

After you pay, we email you a link to set up your account. The link works for 7 days.
If it expired, support can send a new one. It comes from hello@kitebridge.example within
5 minutes and works for 7 days. Use the newest link only. Older links stop working.
