# Log in and find the members area

Last checked: 2026-10-01 · Owner: Support lead · Link: https://kitebridge.example/help/log-in

1. Go to https://kitebridge.example/login.
2. Enter the email you used to pay, then the code we email you. There is no password.
3. The members area opens on the course library. The forum and the call calendar are in the top menu.

If the code does not arrive in 5 minutes, ask for a new one on the same page.
